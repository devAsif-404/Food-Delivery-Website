# TOMATO - Food Ordering Website 🍽️

Hello everyone, I'm Asif Shaikh.
---
This repository contains the source code for **TOMATO**, a full-featured food ordering website built using the **MERN stack**. It provides a user-friendly experience for ordering food online, complete with an admin panel for product and order management.

## ✨ Features

### 🧑‍🍳 User Panel
- Login / Signup
- Logout
- Browse and filter food items
- Add to Cart
- Place Orders
- Stripe Payment Integration
- Order History

### ⚙️ Admin Panel
- JWT Authentication
- Password Hashing (Bcrypt)
- Product Management
- Order Management
- Role-Based Access
- Authenticated REST APIs
- Alerts & Notifications
